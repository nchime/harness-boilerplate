# QA Agent Workflow

이 문서는 프로젝트의 구현이 완료된 후, 결과물을 검증하기 위해 동작하는 **QA(Quality Assurance) 에이전트**의 역할과 체크리스트를 정의합니다.

## 🎯 QA 에이전트의 목표
개발이 완료된 기능이 기획 요구사항(PRD)을 만족하는지, 코드 품질에 문제가 없는지, 빌드가 정상적으로 수행되는지 종합적으로 점검합니다.

## 📋 QA 체크리스트 및 실행 방법

QA 에이전트(AI)는 다음 순서로 프로젝트를 점검해야 합니다.

### 1. 요구사항 검증 (PRD Check)
- [ ] `.agent/prd.md` 파일을 읽고, 명시된 기능(예: Aircat 랜딩 페이지 컴포넌트, 인스타그램 링크 등)이 모두 구현되었는지 확인합니다.
- [ ] 누락된 기능이나 의도와 다르게 구현된 부분이 있는지 리포트합니다.

### 2. 코드 품질 및 정적 분석 (Code Quality)
- [ ] 터미널에서 `npm run lint` 명령어를 실행하여 ESLint 경고나 에러가 없는지 확인합니다.
- [ ] 코드 컨벤션(Harness Engineering 표준)에 어긋나는 하드코딩이나 불필요한 콘솔 로그가 있는지 검토합니다.

### 3. 빌드 안정성 (Build Stability)
- [ ] 터미널에서 `npm run build` 명령어를 실행하여 넥스트(Next.js) 앱이 정상적으로 빌드되는지 확인합니다.
- [ ] 빌드 과정에서 발생하는 타입스크립트(TypeScript) 에러나 의존성 문제를 확인합니다.

### 4. UI/UX 및 디자인 시스템 (Design & UI)
- [ ] Tailwind CSS 클래스들이 적절하게 사용되었는지, 모바일/데스크톱 반응형(Responsive) 처리가 고려되었는지 코드를 통해 검토합니다.
- [ ] Aircat 프로젝트의 테마(프리미엄, 따뜻함, 신뢰감)에 맞는 디자인 일관성이 유지되고 있는지 확인합니다.

## 🚀 QA 에이전트 실행 명령어

이 문서를 기반으로 AI 에이전트에게 QA를 요청하려면 다음 프롬프트를 사용하세요:

> "@.agent/workflow/qa.md 가이드에 따라 현재 완성된 프로젝트의 QA를 진행하고, 결과를 보고서 형태로 출력해줘."
